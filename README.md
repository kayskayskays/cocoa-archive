# cocoa-archive

A small Rust library and CLI for generating archives for a limited set of macOS 
Cocoa objects.

This project is primarily intended to provide a way to generate property list
values for use in macOS applications, especially for the pesky base64-encoded
`<data>` elements.

## Features

- Emulate the [`NSKeyedArchiver`](https://developer.apple.com/documentation/foundation/nskeyedarchiver)
  property list encoding of supported Cocoa objects, currently including:

  - [`NSColor`](https://developer.apple.com/documentation/appkit/nscolor)
  - [`NSFont`](https://developer.apple.com/documentation/appkit/nsfont)
  
- Output binary property lists, optionally base64-encoded

## Installation

You can install the CLI using any of the following methods.

### GitHub

```sh
cargo install --git https://github.com/kayskayskays/cocoa-archive
cocoa-archive --help
```

### Nix

You can run the CLI directly without installing it:

```sh
nix run github:kayskayskays/cocoa-archive -- --help
```

Or install it into your Nix profile:

```sh
nix profile install github:kayskayskays/cocoa-archive
cocoa-archive --help
```

If you use NixOS or Home Manager, you will also be able to use the nixpkgs
package once it is available — coming soon, hopefully!

```nix
home.packages = [
  pkgs.cocoa-archive
];
```

### Source

```sh
git clone https://github.com/kayskayskays/cocoa-archive
cd cocoa-archive
cargo build --release
./target/release/cocoa-archive --help
```

## Usage

```sh
cocoa-archive --help
```

### Examples

```sh
cocoa-archive color \
  --red 1.0 \
  --green 0.0 \
  --blue 0.0 \
  --alpha 1.0 \
  --format binary
```

## Library usage

This crate can also be used for generating archived Cocoa objects from Rust 
code – the public API is basic:

```rust
use cocoa_archive::*;

let target = ArchiveTarget::Color {
    red: 1.0,
    green: 0.0,
    blue: 0.0,
    alpha: 1.0
};

let mut writer = Vec::new();

ArchiverVariant::KeyedArchiver
    .archive(target, ArchiveFormat::Base64, &mut writer)
    .unwrap();

assert!(!writer.is_empty());
```

## Limitations

This is not a complete implementation of `NSKeyedArchiver`.

The archives generated by this library are intended for compatibility with
macOS applications. They are not suitable as a general-purpose replacement for
the archives produced by Apple’s Foundation APIs.
